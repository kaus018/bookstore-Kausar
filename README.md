# Book Store

Тема проекта: Онлайн-книжный магазин

Многостраничный web-сайт книжного магазина с каталогом книг и краткими описаниями произведений. 
Проект разработан с использованием семантического HTML и адаптивного CSS без применения фреймворков и JavaScript.

## Страницы сайта
- Главная
- О магазине
- Каталог книг
- О книгах

## Структура проекта
- index.html — главная страница
- pages/ — дополнительные страницы сайта
- css/ — стили, разделённые по архитектуре
- images/ — изображения проекта

## Используемые технологии
- HTML5
- CSS3
- Flexbox
- CSS Grid

## Архитектура CSS
- reset.css — сброс стандартных стилей браузера
- base.css — базовые стили и типографика
- layout.css — сетка и структура страниц
- components.css — компоненты интерфейса
